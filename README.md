# Programmēšana I — 11. klase

Tukuma Raiņa Valsts ģimnāzija · 3 mācību stundas nedēļā

Šis ir pamatkursa **Programmēšana I** otrā daļa. Pirmā daļa ir 10. klasē
([10-klase](https://github.com/atisozols/10-klase)); abas kopā veido standarta 210 stundas.

## Kā strādāt

1. Katrs **bloks** ir atsevišķs katalogs (`01-…`, `02-…`). Tajā ir:
   - `README.md` — ko mācāmies katrā stundā un kuri uzdevumi jārisina;
   - `teorija.py` / `teorija.sql` / `teorija.js` — piemēri un atgādne;
   - `uzdevumi.*` — **tavs darba fails** ar visiem bloka uzdevumiem.
2. Uzdevumi ir numurēti cauri visam blokam. Uzdevums ar **★** ir papilduzdevums tiem,
   kas tiek galā ātrāk — tas neietekmē vērtējumu negatīvi.
3. Stundas apzīmē ar numuru, piemēram **11-034** — 11. klases 34. stunda.
4. Savu kodu glabā savā GitHub repozitorijā un komitē katrā stundā.
